# Historial de cambios

Este archivo documenta las mejoras principales. Las fechas y versiones de publicación se anunciarán mediante las etiquetas y releases de GitHub.

## Sin publicar — preparación de versión abierta

### Añadido
- Licencia MIT y guía de contribución abierta.
- Reconocimiento explícito de asistencia de inteligencia artificial.
- Documentación de instalación, interpretación de Hz/FPS/Nyquist y limitaciones.
- Indicadores de calidad de señal, FPS estimados y límite de muestreo en la interfaz.
- Pruebas de regresión para señales planas, ruido débil y señales periódicas.
- Flujo de pruebas automáticas para pull requests.

### Mejorado
- Estilo y mensajes de la interfaz.
- Gestión de sesiones y representación del espectro.
- Validación de datos para evitar resultados engañosos.

### Nota
La publicación de una versión estable requiere superar CI y realizar una prueba manual de webcam e interfaz en el sistema de destino.
